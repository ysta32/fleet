# Architecture & module contracts

Pipeline: `config → window → collect (GitHub + Vercel) → summarize (LLM | fallback) → Digest JSON → render (HTML archive) → deliver (Notion / email / ntfy) → save state`.

All shared types live in `src/types.ts` (frozen). Each module below owns exactly one file and exports exactly these names.
Tests live in `test/<module>.test.ts`, use vitest, and **never hit the network** — use fake `FetchLike` + small fixtures in `test/fixtures/`.
Secrets come only from env (`readSecrets`). Never log tokens, never put them in URLs.

`RunOptions` = `{ since?: string; until?: string; configPath?: string; outDir?: string; llm?: boolean; deliver?: boolean; dryRun?: boolean; fetch?: FetchLike; env?: NodeJS.ProcessEnv; now?: Date; log?: (m: string) => void }` (defined in `src/run.ts`, which exports `runDigest(opts: RunOptions): Promise<{digest: Digest; paths: string[]; deliveries: DeliveryResult[]}>`).
`AnthropicLike` = minimal subset of `@anthropic-ai/sdk` client used (`messages.parse` or `messages.create`), defined in `src/summarize/llm.ts`.

## Fleet integration (agreed with Fleet sub-lead)

- Package lives at `packages/digest` in the ysta32/fleet npm-workspace monorepo. Paths above are relative to `packages/digest/`.
- Style: Prettier root config (printWidth 110, singleQuote, trailingComma all). Run `npx prettier --write packages/digest`.
- Tests: `packages/digest/test/**/*.test.ts`, run with `npx vitest run packages/digest/test/<file>` from the repo root (vitest v2). No network.
- Default output dir: `~/.overnight/archive` (env `OVERNIGHT_OUT` / `--out`); state: `~/.overnight/state` (env `OVERNIGHT_STATE`). Fleet daemon serves `<out>/latest.json`.
- `src/render/html.ts` must ALSO export `renderDigestFragment(d: Digest): string` — embeddable HTML (no <html>/<head>), all classes prefixed `ovn-`, plus `DIGEST_CSS: string` (styles scoped under `.ovn-root`). `renderDigestHtml` = full page using both.
- `fixtures/demo-digest.json` = `syntheticDigest(...)` output (SYNTHETIC only), generated by `overnight demo`.
- No `.env*` or `*.jsonl` files anywhere (Fleet CI privacy guard).
